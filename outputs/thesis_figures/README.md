## Key conclusions

1. Full-frame denominator (5M pixels) is dominated by noise-floor integration artifact (~46.8pp of apparent signal)
2. Genuine far-field diffraction peaks (corr >= 0.5 counts above background) contribute only ~5.7pp
3. Within r < 300 support domain: roi_256 captures 87.3%, roi_512 captures 97.4%
4. roi_512 is selected as finite modelling support, not complete physical PSF support
5. Dark frame (mean 24.90, std 0.20) is consistent with scene background (5th percentile 24.98)
