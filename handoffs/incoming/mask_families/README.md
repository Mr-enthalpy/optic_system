# Incoming Mask Family Handoffs

Reserved for future mask specs, explicit masks, or mask sequence specs from
`lcd_mask_families`.

This directory is intentionally non-functional. It reserves a future handoff
boundary only.

Rules:

- do not import `lcd_mask_families`;
- do not define final mask-family schemas here;
- do not implement mask generators, validators, or adapters here;
- do not commit generated large artifacts;
- real data should live in third-party storage or ignored output paths;
- commit only small manifests/spec examples when appropriate.
