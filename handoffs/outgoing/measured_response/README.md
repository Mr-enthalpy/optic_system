# Outgoing Measured Response Handoffs

Reserved for future measured response or target-capture handoffs consumed by
`reconstruction`.

This directory is intentionally non-functional. It reserves a future handoff
boundary only.

Rules:

- do not import `reconstruction`;
- do not implement reconstruction adapters or clients here;
- do not define final reconstruction schemas here;
- do not commit generated large artifacts;
- real data should live in third-party storage or ignored output paths;
- commit only manifests/spec examples when appropriate.
