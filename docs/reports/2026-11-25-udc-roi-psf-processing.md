## 处理规则

沿用既有 ROI/背景/2×2 单元平均/有符号单位总和规则。对三帧均值裁剪 `I`：

```text
b = 64 + mean_border(I - 64)
S = I - b
P = mean of each nonoverlapping 2×2 cell in S
h = P / sum(P)
```

512 ROI 使用 40 native-pixel 边框；128 核心使用 16 pixel 边框。因没有匹配这些亚毫秒曝光的暗场，本项采用已有的边框背景分析方式，**没有拿 10/40/100 ms 暗场冒充匹配暗场**。扣声明黑电平再扣边框残差，数值上等价于扣原 ROI 边框均值。背景可能包含弱信号，不能据此证明尾部全部保留。

所有输出均为 **unit sum，不是 unit peak**。原始 DN 裁剪、背景扣除后有符号副本、归一化前总和及其曝光缩放值分别保留；每档曝光不同，单位总和仅用于形状表示，不保留辐射幅度或证明源功率/QE 校准。不去马赛克、不降噪、不去坏点，不在数值数据中截掉负残差。预览以共同正值对数色标显示，非正值仅在图中显示为黑色。

## 真实观测复核和结果

- 31 档原生 ROI 均与此前已独立验证的全幅均值对应切片**逐像素精确相同**。接收端核对整个原 DN ROI NPZ SHA256，并逐档核对数组 SHA256。
- 保存文件回读后，从原始 DN 使用独立的 `I - mean_border(I)` 公式重算，两种裁剪的 PSF 与保存数组一致；所有 31 档数值有限，单位总和最大误差为 **4.44×10⁻¹⁶**，原 DN 未改变。
- 原采样单位总和 PSF 与 2×2 单元 PSF 之间的块求和关系通过检查；文件不依赖 pickle。
- 此次共享操作、历史 ROI 路径及 UDC 路径专项 **50 passed in 2.14 s**。首次测试被 Windows 沙盒临时目录权限阻断，保留该目录，改用全新目录执行通过；没有把权限错误当成代码通过。未重复完整软件套件，未执行新的硬件采集。

弱尾部存在明显限制：512 ROI 的 `sum(abs(negative h))` 为 **0.754–1.255**，128 核心为 **0.0421–0.0581**。前者说明三帧均值大范围外围的背景/噪声残差不可忽略；这些是有符号经验响应，**不是已验证的非负物理卷积核**。将负值直接归零会引入整流偏差，本项没有用这种方式改善外观或伪装成新观测。较小 ROI 同样不代表全 PSF 能量覆盖；不据此给出完整能量百分比或光谱恢复性结论。
